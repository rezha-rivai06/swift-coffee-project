# HTML Note

## HTML Tags

- `<!DOCTYPE html>` → Declaration for HTML5.
- `<html>` → Root element of an HTML page.
- `<head>` → Contains page metadata and information.
- `<title>` → Sets the browser tab title.
- `<body>` → Contains all visible page content.
- `<main>` → Wraps the primary content of the page.
- `<section>` → Groups related content into one section.
- `<aside>` → Wraps content related to the main content (e.g., sidebar).
- `<h1>` - `<h6>` → Defines heading levels.
- `<p>` → Creates a paragraph.
- `<br>` → Inserts a line break.
- `<pre>` → Displays preformatted text.
- `<style>` → Adds internal CSS styles.
- `<tagname>` → Placeholder for any HTML tag.

---

## HTML Table

- `<table>` → Creates a table.
- `<thead>` → Groups table header content.
- `<tbody>` → Groups table body content.
- `<tfoot>` → Groups table footer content.
- `<tr>` → Creates a table row.
- `<th>` → Creates a header cell.
- `<td>` → Creates a data cell.

---

## HTML Title

- `<title>My Web</title>` → Sets the website title in the browser tab.

---

## HTML Formatting

- `<b>` → Bold text.
- `<strong>` → Important text.
- `<i>` → Italic text.
- `<em>` → Emphasized text.
- `<small>` → Small text.
- `<mark>` → Highlighted text.
- `<del>` → Deleted text.
- `<ins>` → Inserted text.
- `<sub>` → Subscript text.
- `<sup>` → Superscript text.

---

## HTML Quotation & Citation

- `<abbr>` → Displays an abbreviation with a tooltip.
- `<address>` → Displays contact information.
- `<bdo>` → Changes text direction (`ltr` / `rtl`).
- `<blockquote>` → Displays a long quotation.
- `<q>` → Displays a short quotation.
- `<cite>` → Displays the title of a work or source.

---

## HTML Link

- `<a href="">` → Creates a hyperlink.
- `a:active` → Styles an active link.

---

## HTML Visualization

- `<img>` → Displays an image.
- `<map>` → Defines an image map.
- `<area>` → Defines a clickable area inside an image map.
- `<picture>` → Displays responsive images.
- `<svg>` → Creates scalable vector graphics.

---

## HTML Comment

- `<!-- -->` → Adds a comment that is ignored by the browser.

---

## HTML Styling

- `style=""` → Applies inline CSS styles.

### Examples

- `<h1 style="background-color:white">Hello</h1>`
- `<h1 style="background-color:rgb(60, 179, 113)">Hello</h1>`
